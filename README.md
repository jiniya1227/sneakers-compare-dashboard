네이버쇼핑 실시간 가격비교 및 각 브랜드 공식 판매처의 실제 구매자 리뷰를 바탕으로, **50대 여성에게 인기가 높은 10만원 미만 스니커즈·워킹화 3종**의 가격, 핵심 구조 차이, 장단점, 선택 이유를 한눈에 비교할 수 있도록 제작한 반응형 웹 대시보드입니다.

> **디자인 안내:** 본 프로젝트는 카카오쇼핑(톡딜 큐레이션)의 친근하고 가독성 높은 분위기를 참고하여 제작한 **교육·비교용 UI**이며, 특정 브랜드의 공식 로고나 화면을 복제하지 않았습니다.

## 📂 공개 파일 구성

* **`index.html`** : GitHub Pages 메인 접속용 대시보드 페이지 (실물 이미지 Base64 내장, 반응형 UI, 추천 유형 강조 필터, 인쇄/PDF 저장 기능 포함)

## 🚀 주요 기능 및 사용 방법

1. **PC · 모바일 반응형 지원**
   * PC에서는 3열 카드 레이아웃으로 한눈에 비교할 수 있으며, 모바일 화면에서는 1열 카드와 첫 열 고정(`sticky`) 가로 스크롤 비교표로 편리하게 읽을 수 있습니다.
2. **내 선택 이유 체크 & 메모**
   * 상단 `📌 내 선택 이유` 영역에서 본인에게 맞는 신발 카드를 클릭해 체크(`✅`)하고 메모를 입력할 수 있습니다.
3. **인쇄 / PDF 저장**
   * 우측 상단 또는 하단의 **`🖨️ 인쇄 / PDF 저장`** 버튼을 누르면 불필요한 버튼이 숨겨진 깔끔한 1페이지 비교 보고서 형태로 인쇄하거나 PDF로 저장할 수 있습니다.
